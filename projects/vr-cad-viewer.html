VR CAD viewer

A Windows desktop application for viewing CAD models on screen and in a VR headset, built in a team of three for the Software Development group design project.

Role
Developer in a team of three
Year
2025
Tools
C++17, Qt 6, VTK with OpenVR, HTC Vive Pro 2, CMake, CPack and NSIS, Doxygen, GitHub Actions, Git

What it does

You load STL models into a tree-structured scene, set each part's name, colour and visibility, and apply VTK filters such as clip planes and shrink. The same scene can be viewed in a headset, and models can be added or removed while the VR session is running.

What I worked on

  • Model tree. A custom QAbstractItemModel subclass holding each part's name, colour, visibility and filter settings, edited through custom dialogs and right-click menus and rendered in an embedded QVTKOpenGLNativeWidget.
  • VR renderer. A QThread subclass running the VTK OpenVR render loop separately from the GUI thread. Models are added and removed through QMutex-guarded queues that are flushed at frame boundaries, so the renderer is never modified from the wrong thread. A shutdown flag ends the loop and the thread joins cleanly.
  • Rendering. VTK clip plane, shrink and geometry conversion filters, a textured skybox built from JPEG cube faces, and camera, lighting and colour configuration.
  • Build and release. A CMake build that finds and links Qt, VTK and the OpenVR SDK, packaged as a component-based Windows installer with CPack and NSIS.
  • Documentation and workflow. Doxygen API documentation published to GitHub Pages by a GitHub Actions workflow on every push. We worked across forks and feature branches, with pull requests and code review into a shared repository.
