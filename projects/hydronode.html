HydroNodeIn progress

A personal project for monitoring water tanks with LoRa sensor nodes, a gateway and a web dashboard. I'm building it simulator first: simulated sensor nodes stand in for the hardware while the rest of the system is developed.

Progress so far

Check each item below is working before you publish, and remove any that are not

  • A FastAPI REST backend with PostgreSQL persistence through SQLAlchemy and psycopg: POST /readings for ingestion, GET /readings for retrieval, and a database health check.
  • Duplicate protection at the database level, using a uniqueness constraint on node ID and sequence number so retransmitted readings are not stored twice.
  • A Python UDP gateway layer that bridges simulated node traffic to the HTTP backend, keeping edge and gateway functionality separate from the central server.
  • A React and TypeScript frontend foundation, built with Vite, for viewing readings.
  • Separate backend, gateway and frontend services, with PostgreSQL running in Docker and environment-based configuration.
